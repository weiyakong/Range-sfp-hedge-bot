# Macro subsegment types — Stage 2b

This label-free stage clusters only validated Stage 2a candidate subsegments.
It uses compact summaries of the validated normalized 4H sequence, reorients
exact directional primitives to each subsegment's own net movement, and applies
one fixed-seed k-means method over k=2..6 after clusterability diagnostics.
Neutral `Type A`, `Type B`, etc. are descriptive identifiers, not market
semantics. Parent-leg sequence analysis and macro-leg overlays are out of scope.
